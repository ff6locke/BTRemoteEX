# BTRemoteEX
Android Bluetooth HID Air Mouse prototype for Rocktek GX1.
- Touchpad pointer movement
- Left/right click buttons
- Scroll up/down
- Android 9+ (Bluetooth HID Device profile)
Build debug APK using GitHub Actions.
Pairing: launch the app, tap Start Bluetooth Mouse, then pair BTRemoteEX from the GX1 Bluetooth settings. HID Device support is dependent on phone firmware.
